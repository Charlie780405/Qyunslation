# 组件与交互子纲领

## 设计令牌

先在单一令牌层定义颜色、字体、间距、圆角、阴影、层级和动效；Vue/Tailwind 与 Gradio 补丁都映射同一语义令牌。

| 令牌 | 建议 |
| --- | --- |
| 主色 | 使用品牌蓝/青之一作为动作色；绿色只表达成功，不与主操作竞争 |
| 中性色 | 白色文档纸面 + 低饱和灰工作区；边界依靠 1px 线和空间，不堆卡片阴影 |
| 字体 | UI 使用系统无衬线；文档画布忠实呈现原文件，编辑器明确显示替代字体状态 |
| 字号 | UI 正文 14–16px，辅助信息不低于 12px；不得用微字塞进表格/图片 |
| 间距 | 4px 基线；常用 8/12/16/24/32px |
| 圆角 | 控件 6–8px、容器 8–12px；文档页保持纸张直角或极小圆角 |
| 动效 | 120–200ms；遵守 `prefers-reduced-motion`；长任务不用无意义循环动画 |

状态颜色必须同时配图标和文字，不能仅靠红/绿。链接、引用编号与可点击对象要有统一视觉语义。

## 核心组件

### `UploadDropzone`

- 支持点击和拖放，明确 PDF/DOCX/图片、大小和页数限制。
- 文件选择后立即显示文件名、大小、类型、校验状态和移除操作。
- 错误贴近文件项，并说明如何修复；不要只弹一次性 toast。
- 移动端不使用“拖放”作为唯一文案。

### `DirectionSwitch`

- 只有 `中→英`、`英→中` 两态，交换按钮有可访问名称。
- 自动检测显示“检测为中文，可修改”，不能隐藏最终方向。
- 任务开始后方向锁定；修改需明确创建新代际或重新开始。

### `PreflightSummary`

- 以“19 页｜双栏 12 页｜Figure 5｜Table 3｜图片 OCR 2｜参考文献 2 页”呈现。
- 数量可点击筛选对应对象；不确定数量显示 `待确认`，不显示 `0`。
- `truncated/blocked/degraded` 使用独立状态横幅并给出下一步。

### `JobStageBar`

- 阶段：校验、预扫描、文本翻译、表图翻译、版式生成、QA。
- 展示已知的页/对象进度；只有数据可靠时才显示 ETA。
- 取消、重试和后台运行是文本动作；取消前说明已完成结果是否保留。
- 失败时停在故障阶段，不把进度条涂满。

### `PageCanvasPair`

- 原文画布只读，译文画布可显示对象选区；二者共享页/对象导航而非共享像素偏移。
- 原文缩略图和放大渲染采用足够清晰的源（目标 300 DPI 或等效渐进瓦片），先出低清占位再无跳动替换。
- 同步开关必须说明同步的是页、对象还是滚动；旋转页保存独立方向。
- 全屏、适宽和重置视图必须键盘可用；工具栏不能遮住文档正文。

### `ObjectInspector`

- 标题显示对象类型、页码和序号，例如“表 2 · 脚注”而非内部 UUID。
- 原文、译文、术语/TM、格式、历史分组；常用编辑不需要多层标签嵌套。
- 保存采用明确状态：未修改、保存中、已保存、冲突、失败。
- 富文本只开放源格式需要的粗体、斜体、上下标、链接等，不提供通用排版工具栏。

### `TableEditor`

- 在页面上下文中高亮当前表格，并提供单元格网格/原图两种查看方式。
- 行列标题、合并单元格、粗体、对齐、字号层级和脚注都来自结构数据。
- 翻译状态按单元格与脚注分别统计；缩写可保护，但脚注仍须翻译。
- 字号异常、溢出或未译文本形成 QA，不通过无限缩小字体解决。

### `FigureTextEditor`

- 显示原图、擦除/回写预览和 OCR 文字框；点击列表同步高亮框。
- 每个框显示原文、译文、置信度、字体大小/粗体/对齐和溢出状态。
- 支持恢复原文图片和重新生成单个对象；绝不能修改原文资产。
- 小字优先提供局部放大，不用放大译文字体破坏层级。

### `TerminologyPanel`

- 分为首选译法、保护/不译、禁用译法、变体；显示词库、版本、来源和适用方向。
- 命中词在原文与译文中轻量标注；用户可接受候选或从选区提交新术语。
- 新术语先进入待审核，不自动污染全局词库。
- 医药缩写保留原文时，首次展开、脚注释义和单位仍按规则处理。

### `QAList`

- 分阻断、警告、信息；按页、类型、未解决状态筛选。
- 问题文案包括“发生了什么、在哪里、为何重要、怎么修复”。
- 每条可跳转、解决、忽略并填理由；批量操作必须限定同类规则。
- 重点规则：漏译、术语不一致、数字/剂量改变、表/图未译、脚注遗漏、字体溢出、参考文献被改写。

### `DownloadMenu`

- 主动作下载推荐产物；次级选项包括双语 PDF、单语 PDF、DOCX（若支持）、QA 报告。
- 清楚标示正式版/审阅稿、生成时间、词库版本和未解决问题数。
- 未通过阻断门禁时，不把审阅稿伪装成正式完成稿。

## 无障碍与键盘

- 所有可点击元素使用 `button/a/input`，不要用无语义 `div`。
- 使用 `:focus-visible` 提供高对比焦点环；不得全局移除 outline。
- 图标按钮有 `aria-label` 与 tooltip，切换控件有状态和值。
- 长任务状态用礼貌的 live region，避免每个百分比都打断读屏。
- 抽屉打开后管理焦点、支持 `Esc` 关闭并把焦点还给触发器。
- 页面画布本身不是唯一的信息载体；选中对象和 QA 同时有文本列表。

## 前端实现边界

- 页面负责组合，领域状态放 composable/store，网络与 Manifest 适配放服务层，组件不直接解析后端日志。
- 组件优先单一职责；超过约 200 行或同时处理网络、领域状态和渲染时拆分。
- 任务 ID、页码、选中对象和模式可进 URL/可恢复状态；缩放等瞬态视图状态留本地。
- 服务端任务状态使用单一缓存/轮询源；禁止每张卡片各自发重复轮询。
- 上传内容、文件名、错误文本和 iframe/srcdoc 都按不可信输入处理；预览采用受限来源与 CSP/沙箱。

1. 先定位实际运行的是 Gradio 补丁链还是 Vue，停止双轨盲改。
2. 恢复全局 `focus-visible`，给底部图标操作加名称并移入任务上下文。
3. 用语义阶段与问题对象替换主区域原始日志。
4. 将预览从 offcanvas 提升为中央主画布。
5. 用 Manifest 页/对象锚点替换百分比同步滚动。
6. 合并 Bootstrap/Tailwind/行内色值为一套语义令牌。
7. 再建设专业检查器、术语/TM 和 QA；不要在基础工作台未稳定时堆功能。
