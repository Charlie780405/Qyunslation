# 工作台信息架构与流程子纲领

## 目标用户

| 用户 | 首要任务 | 界面默认 |
| --- | --- | --- |
| 医药研发阅读者 | 快速获得可读、可下载的中英译文 | 快速模式 |
| 医学翻译/审校者 | 校术语、数字、表图、格式并留痕 | 专业模式 |
| 运营/管理员 | 看任务健康、失败原因、词库版本 | 独立管理入口，不挤入翻译主界面 |

## 顶层结构

### 应用栏

- 左：品牌 + 当前文档名；超长文件名中间省略，悬停可见全名。
- 中：中→英 / 英→中方向、任务状态、保存状态。
- 右：模式切换、帮助、账户；服务健康只在异常时出现。
- 不在应用栏堆 OCR、模型地址、线程数等工程参数。

### 左侧工作坞

桌面默认 300–340px，可收起到 56px；包含：

1. 上传/当前文档与队列；
2. 基本选项：方向、文档类型、翻译策略；
3. 预扫描摘要：页数、栏型、Figure、Table、可翻译图片、受保护区域；
4. 结构问题与降级提示；
5. 固定在可见区底部的主操作：翻译、取消、重试或下载。

高级参数使用分组抽屉，并提供“恢复推荐值”。内部引擎名可用于诊断，不作为普通用户必填项。

### 中央文档画布

- `>=1440px`：原文与译文双画布，支持 40/60–60/40 拖动，任何一栏不小于 480px。
- `1024–1439px`：双画布保持，但右检查器改抽屉；窄到最小宽度时自动改标签切换。
- `<1024px`：同一画布用“原文 / 译文 / 对照”切换，不强塞两个缩小页面。
- 页缩略图是按需展开的导航，不应永久侵占宽度。
- 工具栏包含页码、缩放、适宽、旋转、同步、全屏；每个图标必须有文本名称/提示。
- 选中段落、标题、表格单元格、图片文字或脚注后，以相同 `object_id` 打开检查器。

### 右侧对象检查器

专业模式显示 340–400px 检查器，按当前对象提供：

- 原文、目标译文与编辑器；
- 对象类型、页码、阅读顺序和版式属性；
- 术语命中、候选译法、翻译记忆与受保护词；
- QA 问题、处理动作和历史；
- 表格单元格导航或图片文字框预览。

检查器无选中对象时显示文档级 QA 摘要，不显示空白大面板。

## 核心流程

### A. 快速翻译

```text
上传 → 文件校验 → 预扫描 → 确认方向/类型 → 翻译 → 结果摘要 → 下载
```

- 预扫描成功后自动给出推荐配置，但不得自动开始产生费用或长任务，除非用户明确开启。
- 摘要显示语义对象而不是“检测到 N 张资源图”；同一 Figure 的分块资源只计一个 Figure。
- 结果页显示成功、降级和待复核数量；“生成了 PDF”不等于全部质量门禁通过。

### B. 专业审校

```text
打开结果 → QA 问题队列 → 跳转对象 → 对照/编辑 → 确认或忽略 → 再验证 → 导出
```

- 默认先显示阻断问题，再显示警告。
- `J/K` 可切上一/下一问题，`Ctrl/Cmd+Enter` 确认当前对象，`Esc` 退出编辑。
- 对修改过的对象显示“已编辑”，对受术语保护的对象显示规则来源。
- 导出前重新运行文档级 QA；仍有阻断问题时禁用正式导出，但可下载带水印的审阅稿。

### C. 失败恢复

```text
失败/超时/截断 → 保留已完成阶段 → 解释原因 → 给出可执行方案 → 从安全检查点重试
```

- “查看技术详情”包含错误 ID、阶段、页码、运行时和可复制诊断，不向普通用户倾倒堆栈。
- 切换文件或重跑时使用 generation/token 防止旧回调覆盖新任务。
- `blocked` 表示缺样本/依赖/权限等无法继续；`degraded` 表示完成但能力降级，两者不可混用。

## Manifest 到界面的映射

| Manifest 数据 | 界面位置 | 禁止做法 |
| --- | --- | --- |
| `pages[]` / 页面方向 | 页导航、旋转标识 | 用 PDF 视图当前滚动位置反推总页数 |
| `layout_mode` / columns | 预扫描摘要、页级徽标 | 只显示“学术文献”而隐藏多栏差异 |
| Figure/Table/可翻译图片对象 | 摘要、对象列表、QA | 统计底层 image xref 数量 |
| `object_id` / reading order | 双画布同步、检查器、历史 | 使用像素百分比作为唯一对应关系 |
| exclusions / references | 受保护区样式、跳过原因 | 静默不译或按关键字临时判断 |
| issues / capabilities | QA、降级横幅、导出门禁 | 从日志文本正则提取状态 |

## 参考文献区策略

- 识别为 references/bibliography 的整区保持原文，包括章节标题、作者、文章标题、期刊、年份、DOI 与 URL。
- 原文与译文画布均显示该区，但译文侧增加轻量“原样保留”标识；不要用整块灰遮罩影响阅读。
- 若结构识别置信度不足，显示待确认边界，禁止静默翻译部分条目。
- “补充材料”“致谢”等相邻章节不能因靠近参考文献而自动继承保护策略。

## 响应式矩阵

| 宽度 | 画布 | 左工作坞 | 右检查器 | 主操作 |
| --- | --- | --- | --- | --- |
| `<768` | 单画布标签切换 | 全屏抽屉 | 全屏抽屉 | 底部固定，避开安全区 |
| `768–1023` | 单画布 + 快速原译切换 | 抽屉/窄栏 | 抽屉 | 底部或工作坞内固定 |
| `1024–1439` | 双画布或用户选择单画布 | 280–320px | 抽屉 | 左栏固定 |
| `>=1440` | 可调双画布 | 300–340px | 340–400px 可收起 | 左栏固定 |

## 导航边界

- `/`：上传和最近任务；未登录也能理解价值与限制。
- `/jobs/:id`：唯一翻译工作台，快速/专业是模式而非两条路由。
- `/glossaries`：术语资产、审核和版本。
- `/history`：任务与导出历史。
- 管理/诊断功能单独授权，不出现在普通用户主导航。
