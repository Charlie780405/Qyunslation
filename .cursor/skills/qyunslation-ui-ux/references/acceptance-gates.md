# UI/UX 验收门禁子纲领

任一必需门禁为 `FAIL` 或 `BLOCKED` 时，不得报告界面完成。证据应记录到对应 WT，而不是只写“人工看过”。

## 1. 运行时门禁

- 记录生产/验收服务的启动入口、提交、实际静态资源或 Gradio 页面来源。
- 证明修改文件被真实运行时加载；若有 `apply-pdf2zh-*` 补丁，记录最终覆盖顺序。
- 浏览器无新增 console error、未处理 promise、资源 404 或循环请求。
- 刷新任务页后状态可恢复，旧 generation 回调不会污染新任务。

## 2. 核心任务门禁

分别用 PDF、DOCX 和图片完成：

```text
上传 → 校验 → 预扫描 → 确认配置 → 翻译 → 查看 QA → 定位对象 → 下载
```

- 主路径不要求理解 OCR、Manifest、xref、缓存等工程术语。
- 每一步只有一个明确主动作，次级操作不会与主动作同权重竞争。
- 失败、取消、重试、断线恢复和切换文档均有确定结果。

## 3. 文档语义门禁

- 页数、Figure、Table、可翻译图片和参考文献区数量与 Manifest 一致。
- `unknown/truncated/blocked/degraded` 不显示为 0、成功或绿色完成态。
- 原文资产不被替换或写回；译文修改有版本与恢复入口。
- 参考文献整区原样保留，包含章节标题和文章标题；界面显示跳过原因。
- 表格有单元格与脚注状态；脚注可翻译，缩写保护不导致脚注漏译。
- 图片文字框可审校，字号/粗体/对齐与溢出状态可见。

## 4. 视觉门禁

在 320、768、1024、1440px 宽度分别截图：

- 页面无水平滚动条、控件遮挡、标题截断或译文栏裁切。
- 文档视图保持可读最小宽度；空间不足时切单画布，不无限压缩双栏。
- 长文件名、长中文、长英文术语、100%/200% 缩放和旋转页不破版。
- 加载骨架尺寸稳定，清晰页面替换低清占位时无明显布局跳动。
- 表格和图片局部放大可用；原文预览达到 300 DPI 或等效可辨识清晰度。
- 颜色、间距、圆角和阴影来自统一令牌，没有新增孤立视觉体系。

## 5. 无障碍门禁

- 只用键盘可完成上传、启动、切原译文、导航问题、编辑、保存和下载。
- 所有交互有可见焦点；焦点顺序符合视觉顺序，抽屉/对话框焦点可返回。
- 图标按钮有可访问名称，输入有 label，错误与对应字段关联。
- 文本和非文本对比度满足 WCAG 2.1 AA；状态不只依赖颜色。
- 200% 浏览器缩放和系统大字号下仍可完成核心路径。
- `prefers-reduced-motion` 下关闭非必要动效；长任务公告不会刷屏读屏器。

## 6. 交互与状态门禁

自动覆盖：

- 空、加载、部分数据、成功、失败、取消、超时、截断、降级和陈旧回调；
- Manifest 缺字段/新版本时 fail-closed，而不是静默猜测；
- 页/对象同步在不同页高、旋转页、跨页表和单栏/多栏组合中仍定位正确；
- QA 点击能跳到准确对象，解决/忽略后计数和导出门禁一致；
- 双击启动、重复取消、网络重试不会创建重复任务或重复下载。

## 7. 真实样本矩阵

| 样本 | 必看问题 |
| --- | --- |
| 单栏学术 PDF | 标题粗体、段落、参考文献保护 |
| 双栏/多栏 PDF | 阅读顺序、原译文锚点、栏间不串行 |
| 旋转大表 | 表格识别、单元格字号、脚注、旋转同步 |
| 流程图/图片 OCR | 文字框、字体层级、溢出、原图不变 |
| 扫描 PDF/纯图片 | OCR 状态、置信度、300 DPI 预览 |
| DOCX | 标题/表格样式、分页和导出格式 |
| 失败/截断夹具 | 状态解释、恢复和不得写成功缓存 |

## 8. 性能体验门禁

- 用户操作后 100ms 内有按压/选中反馈；超过 1s 的操作显示状态。
- 首屏先呈现外壳与当前任务，重型 PDF 视图、缩略图和检查器按需加载。
- 只渲染可视页面/缩略图；切页与缩放不触发整个任务树重复计算。
- 轮询退避且页面隐藏时降频；完成/失败后停止轮询。
- 长任务期间导航、取消和技术详情仍可响应。

## 9. 交付证据

WT 至少包含：

- 修改前后同尺寸截图与真实样本名称；
- 运行时入口与加载证明；
- 断点矩阵、键盘路径和关键状态结果；
- 自动测试、构建、浏览器 console/network 结果；
- 未解决风险、降级行为和回滚方式。
