# PLAN-041c：单元格级翻译与安全回写

> 状态：**已完成**
> 父计划：[PLAN-041](./PLAN-041-pdf-regulatory-form-fidelity.md)

## 实施

1. 根据网格边界、缺失分隔线和文字中心重建单元格及合并关系。
2. 单元格按阅读顺序翻译，保护缩写、数值、单位、注册号、方案号、联系方式和药物代码。
3. 在目标页先以保留图形的 redaction 移除源文字，再绘制译文；禁止只用白色遮挡留下可提取原文。
4. 表头/分组标题继承粗体，正文与脚注继承字号层级；同层级采用一致的字号决策。
5. 双语 PDF 只处理右栏坐标，左栏和原文 PDF 不得被改动。

## 验收

- 译文文本抽取不再包含被替换的中文原文。
- 边框、合并单元格、数字及不可变字段保持完整。
- 粗体角色和字号层级通过程序化门禁与页面渲染抽查。

- 真实 7 页样本仍精确识别 14 表，形状与逐页分布全部命中；单元格行列索引越界为 0，识别 66 个合并块。
- 注册号、方案号、电话、邮箱和日期均由占位保护并在译后逐项复核；丢失任一 token 即 `TABLE_TOKEN_DRIFT`。
- 合成 PDF 验证 redaction 后源中文不可提取、矢量边框仍在；双语右栏处理前后左栏像素哈希一致。
