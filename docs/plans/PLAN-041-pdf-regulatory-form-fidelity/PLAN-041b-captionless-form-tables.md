# PLAN-041b：无题注临床表单识别

> 状态：**待执行**
> 父计划：[PLAN-041](./PLAN-041-pdf-regulatory-form-fidelity.md)

## 实施

1. 从矢量绘图提取短边框线，先按共线与相交关系拼接，再做长度过滤，避免 Word 单元格分段边框丢失。
2. 以连通网格组件识别无 `Table N` 题注的候选区，要求至少两条横轴、两条纵轴且内部有文字。
3. 从登记号、试验状态、入排标准、研究者信息等版面/词汇信号建议 `REGULATORY` 画像。
4. 将候选表格加入单页预计算上下文并供正文排除区复用，避免重复分析。
5. 运行时禁止 `page.find_tables()`；该 API 只允许在离线金标对照工具中使用。

## 验收

- 合成无题注表单、合并单元格和跨页续表均可识别。
- 真实 7 页样本为 `4/1/2/1/1/1/4`，网格形状与父计划金标一致。
- 7 页扫描 `<5s`，且 monkeypatch `page.find_tables` 为失败函数后仍通过。
