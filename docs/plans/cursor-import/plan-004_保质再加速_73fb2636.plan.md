## PLAN-004c：上调 LLM 批阈值（有门禁）

### 背景（已读源码，不是「2 段改 4 段」）

[`process_page`](/home/dev/.local/share/uv/tools/pdf2zh-next/lib/python3.12/site-packages/babeldoc/format/pdf/document_il/midend/il_translator_llm_only.py) 已有：

```python
if total_token_count > 200 or len(paragraphs) > 5:
    executor.submit(self.translate_paragraph, BatchParagraph(...))
```

即 **>200 tiktoken 或 >5 段** 就提交一批。每批仍带完整 Structure Rules JSON prompt。把阈值略加大，可减少 HTTP/prefill 次数；JSON 对不齐会走已有 fallback（质量风险在这里）。

### Task C1 — 补丁旋钮

`apply-pdf2zh-throughput.py` 把硬编码改为：

- `total_token_count > 400`（原 200）
- `len(paragraphs) > 8`（原 5）

环境变量可覆盖：`PDF2ZH_LLM_BATCH_TOKENS` / `PDF2ZH_LLM_BATCH_PARAS`，默认 400/8。

**Acceptance：** `rg` 可见 400 与 8（或 env）；无其它逻辑改动。

### Task C2 — fallback 门禁（10 页）

同一份 10+ 页文字 PDF：

1. 先用默认 200/5 跑，记 `fallback_count / total`（babeldoc 已打 `Fallback:`）
2. 再 400/8 跑，比 fallback 率

**门：** 新 fallback 率 **不得 ≥ 2 × 基线**。触发则阈值改回 200/5，004c 标失败，**不阻塞** 004b 成果，**不开** 004d。

### Task C3 — QnA SLO

无术语轮、qps=4、004a 已生效：`QX027N QnA` 级（~800 段）墙钟 **≤10 min**。

**Acceptance：**

| # | 项 | 期望 |
| --- | --- | --- |
| C-V1 | 批阈值 | 400 / 8 或已回滚并写明原因 |
| C-V2 | fallback 门 | 通过或已回滚 |
| C-V3 | QnA 墙钟 | ≤10 min（门通过时） |
| C-V4 | 3 页抽检 | 对照 DT-2026-0002 无漏段 |

### 004c 回滚

阈值改回 `200` / `5`。
