### 四条题注驱动规则

```mermaid
flowchart TD
    page[页面] --> anchors[caption_anchors 取题注]
    anchors --> kind{页型}
    kind -->|仅 table 题注| blocked["规则A 纯表页 fail-closed"]
    kind -->|仅 figure 题注| figpage["规则B 忽略 find_tables 假命中"]
    kind -->|无题注| legacy["沿用现有几何逻辑"]
    figpage --> relax["规则C min_drawings 放宽"]
    relax --> cluster[聚类与面积正文关卡]
    cluster --> group["规则D 按题注归组合并"]
    group --> area{合并后超面积上限}
    area -->|是| fallback[回退拆块]
    area -->|否| out[一图一区域]
```

规则 C 的放宽**只对有 figure 题注的页生效**。实测全局把 `min_drawings` 降到 2 会让幻灯样本区域从 12 涨到 19，破坏 PLAN-029b 标定；幻灯页题注数为 0，天然走 legacy 分支。
