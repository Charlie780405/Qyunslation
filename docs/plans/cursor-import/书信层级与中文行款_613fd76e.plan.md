# PLAN-009：书信角色字号与中文行款

在 PLAN-008 `letter` 模板上补层级，**不重排整页**。信头/地址/正文/落款仍落在原信对应盒子里，只改字号、缩进、对齐和中文标点。文献 / IND 模板本 PLAN 不动。不改泰州 HPD。

## 现状（页 1 V6e）

[letter.mono.png](deliverables/plan-008-profiles/letter.mono.png) 已无中英叠字，但全文同一字号，且行款不像中文公函：

- 信头「美国食品药品监督管理局」与正文一样大
- 「给药」是 FDA 徽标碎片，应丢掉或并进信头
- 地址 `4 ( ^{th} ) Floor` 是 OCR 上标泄漏
- 「我们对您会议问题的初步回复如下：」被排成居中小标题（半句独立块的后遗）
- 「此致」漂在页中；落款多行挤在一起、未右齐
- 正文未段首缩两字

## 排版规格（只对 `letter`）

角色由**几何 + 文本**判定，不依赖版式模型。页 1 实测锚点：信头 y&lt;0.22 页高；地址在称谓之上；落款 x0&gt;0.32 页宽且在正文之下。

| 角色 | 判定 | 字号 | 行款 |
| --- | --- | --- | --- |
| header | 页顶 22% 或匹配 FDA/PIND/会议初步意见 | 9pt | 居中或保持原 x；去掉「给药」类 1–2 字碎片 |
| address | 称谓之前的左栏 | 9pt | 左齐、行距 1.25；清洗 `^{th}` → `4层` |
| salutation | `Dear` / `尊敬的` | 10.5pt | **顶格**，不缩进 |
| body | 其余长段 | **12pt** | **段首全角缩两字**；行距 1.5；中文标点全角化 |
| closing | `Sincerely` / `此致` | 9.5pt | 左空两字或保持原 x，**不居中** |
| signature | 正文下方偏右块 | 9pt | **块内右齐**；职务一行一行断，行距 1.25 |
| footer | `ENCLOSURE` / `附件` / `Reference` | 8.5pt | 左下，保持原位 |

字号是目标值，盒子放不下时仍走现有 `_fit_fontsize` 下限（信头/落款 8pt，正文 10pt），禁止再缩到 5pt。

```mermaid
flowchart TD
    HPD[hpd_ocr 段落盒] --> Tag[letter_layout.tag 角色]
    Tag --> Clean[清洗 ^{th} / 碎片]
    Clean --> Babel[BabelDOC 翻译]
    Babel --> Style[letter_layout.apply 字号/缩进/右齐]
    Style --> Out[白底中文信]
```

## 实现

### 009a 角色标注与清洗（本地，不调 HPD）

新增 [scripts/letter_layout.py](scripts/letter_layout.py)：

- `tag_blocks(boxes, page_w, page_h) -> list[role]`
- `clean_text(text)`：`^{th}` / `( th )` → `4层`；单独的 `给药`/`FDA-`/`‑` 丢弃或并入邻块
- 页 1 夹具断言：`Please refer`/`We also` → body；`Dear` → salutation；`Sincerely`/`Crystal` → closing/signature；`PIND` → header

在 [scripts/hpd_ocr.py](scripts/hpd_ocr.py) 聚合之后、`insert_textbox` 之前调用（仅当 `profile=letter`）。把 role 写入 debug JSON，便于对照。

### 009b 模板字段

扩展 [scripts/doc_profiles.toml](scripts/doc_profiles.toml) 的 `[letter]`：

```toml
body_font_size = 12.0
meta_font_size = 9.0          # header/address/signature
salutation_font_size = 10.5
closing_font_size = 9.5
footer_font_size = 8.5
body_first_indent = true
signature_align = "right"
```

其它模板不加这些键，`letter_layout.apply` 无键则 no-op。

### 009c 译后排版（BabelDOC IL，运行时 patch）

在 [scripts/doc_profile.py](scripts/doc_profile.py) 增加 `patch_letter_typesetting()`，仅 `letter` 启用：

1. 翻译完成后、`Typesetting.render_page` 里按段落 y/x/文本再标一次角色（译后中文：`尊敬的`/`此致`/`附件`）
2. 改该段 `pdf_style.font_size` 为目标值
3. body：若段首无 `　　` 则插入两个全角空格
4. signature/closing：对该段排版从 `box.x2` 往左排（在 `_layout_typesetting_units` 包一层，按段 `align=right`）
5. 落款行距用 1.25，正文用模板 `line_skip=1.5`

不改 babeldoc 源文件；与现有 `patch_line_skip` 一样运行时注入。函数名变了则降级并 warning。

### 009d 页 1 验收

- bench 变体 `V7`（letter + 009），产出 `deliverables/plan-009-letter/`
- 门槛（左页译文）：
  - 正文字号中位 ≥ 11pt
  - header/signature 字号中位 ≤ 正文中位 − 1.5pt
  - 至少一个 body 段以 `　　` 开头
  - 落款块右缘比正文右缘更靠右（或落款 x0 &gt; 页宽 × 0.35）
  - 全文无 `^{th}`、无孤立「给药」
  - 无中英叠字（内容流 `Do` 图像 = 0，沿用 008 补丁）
- [scripts/verify-plan-009.sh](scripts/verify-plan-009.sh)、`docs/plans/PLAN-009-letter-typography/`、`docs/walkthroughs/WT-009-letter-typography.md`

## 风险

- 角色误判会把短正文当成落款。用「偏右 + 在称谓之后」双条件，夹具覆盖页 1
- 右齐依赖 typesetting 内部函数，升级可能失效；失败则只改字号/缩进，对齐保持左齐并记 warning
