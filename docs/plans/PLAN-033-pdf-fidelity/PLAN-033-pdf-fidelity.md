# PLAN-033：学术文档图表识别、翻译与版式保真

状态：计划已递交，待实施。基线为 `775d0c1`（PLAN-030h 最新实现）。

## 摘要

解决当前 PDF 翻译链路中图表数量不准、表格漏译、参考文献误译、原文侧被图片翻译污染、预览模糊、图表字体不一致以及多栏排版失真的问题。首要验收样本为现有 11 页学术 PDF；实测语义对象为 Figure 1–2、Table 1–4，而当前扫描器仅返回 2 个 Figure、1 个 Table。

当前根因已确认：caption span 拼接后形成 `Table 2Response...` 等无空格文本，导致 Table 2–4 未被识别；外部 BabelDOC 的 RapidOCR 表格适配器是兼容性空实现；GUI 先生成 `.imgtr.pdf` 再交给 BabelDOC，使双栏输出的“原文”半边也包含图片翻译结果；预览 canvas 使用屏幕级分辨率后再放大，造成模糊。

## 实施子计划

### 033a：基线、计数契约与数据模型

- 增加结构扫描算法版本，并将版本写入 Manifest/cache key；旧缓存自动失效，截断或失败结果不得入缓存。
- caption 解析改为基于行/词块/span 的解析，保留空格与阅读顺序，支持 `Figure/Fig`、`Table`、补充材料和跨行标题；正文引用如“see Table 4”不得计为对象。
- Manifest 统一记录对象角色、页码、栏/流区域、bbox、置信度、来源（文本层/OCR/矢量）及翻译状态，计数必须来自唯一语义对象。

### 033b：表格、图片与脚注翻译

- 建立仓库内表格区域和单元格提取器：优先使用文本词块、线段和列/行间隙，边界不完整时使用 300 DPI OCR；不调用当前空实现的 RapidOCR table adapter，也不依赖 Camelot/Java。
- 表格输出保留边框、行列、数值、单位和缩写；翻译 caption、单元格文本及表格脚注。缩写本体可按术语策略保留，但脚注必须翻译；低置信度进入显式告警/人工复核，不得静默漏译。
- 图片翻译按语义角色分组：标题、标签、正文、图注/脚注分别统一字号；优先换行、扩展可用区域和调整字距，禁止单个文本块异常缩小或放大。嵌入资源与预览统一使用 300 DPI 目标。

### 033c：原文不可变与翻译执行顺序

- 原始上传文件只读并保留 hash；BabelDOC 始终以原始 PDF 为输入。
- 先生成正文译文，再对单语译文和双语译文右侧译文半边执行图片/表格后处理；双语 PDF 左侧必须与原始文件逐页一致，不能再使用 `.imgtr.pdf` 作为 BabelDOC 输入。
- 兼容 PDF、DOCX、PPT/PPTX、PNG/JPEG/TIFF、poster 等输入，统一经过规范化画布和对象 Manifest；已有入口/格式能力保持兼容。

### 033d：参考文献与多栏版式

- 参考文献区只翻译“参考文献/References”标题；作者、题名、期刊、DOI、URL、卷期页码和条目正文原样保留，并排除术语自动采集。正文中的引用仍正常保留。
- 补齐单栏、双栏和三栏以上列检测，处理靠近中线的栏归属、跨栏标题、poster/freeform 页面及图表混排；禁止跨栏文本拼接。
- 同一栏/流区域内同级段落采用统一间距，标题与下一段保持整体；剩余空白放在流区域末端。译文行数、栏宽、页数、MediaBox/CropBox/rotation 必须可追踪，禁止泄漏内部占位符。

### 033e：300 DPI 懒加载预览与运行可观测性

- 当前页按 300 DPI 懒加载并缓存，翻页时再生成后续页面；下载 PDF 继续保持可搜索文本和原始矢量/图表质量。
- 进度同时展示页数、语义对象数、图片/表格数量、已翻译/跳过/告警数量；不要把内部 OCR/资源步骤数伪装成图片数量。
- Manifest 记录 LLM provider、base URL、model id、配置快照摘要和版本。当前运行配置确认为泰州 Ollama `qwen3.6:35b-a3b`，增加运行时探针以便发现配置漂移。

### 033f：测试、门禁与交付

- 增加真实样本金标及合成夹具，覆盖单栏、双栏、多栏、图表混排、无标题图、纯图片页、表格脚注、参考文献、PDF/DOCX/PPT/图片/poster。
- 计数验收：11 页样本必须为 Figure=2、Table=4；图表均有唯一 ID，表格均有可翻译区域，参考文献条目正文零改动。
- 双语输出左侧与原文逐页 hash/渲染对比一致；原始文件 hash 不变；译文图表无漏译、无重叠、无异常字号，300 DPI 预览清晰。
- 增加字体一致性、同级段落间距、栏归属、页数/尺寸保持、缓存失效、失败回滚和重复运行幂等测试；执行聚焦结构测试、完整 structure 测试、PLAN-028/029/030h 门禁及跨格式回归。
