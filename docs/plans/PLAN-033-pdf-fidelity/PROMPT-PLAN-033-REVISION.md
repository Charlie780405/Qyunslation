## 必须解决的用户结果

1. 原文标题/小标题为粗体或斜粗体时，译文保持同等字重、斜体和层级；普通正文不得被误加粗。
2. 图片/流程图中文字不得越框、截断或小到不可读；同一语义角色采用一致字号，粗体状态与原图一致。

4. 表格标题、表头、分组行、正文、脚注分别保持统一字号；原文粗体单元格在译文中仍为粗体。
5. 参考文献标题可本地化，但标题之后的每条书目记录必须逐字保留原文，包括作者、文章标题、期刊、年份、卷期页码、DOI、URL；跨栏、跨页和续页不得重新进入翻译队列。
