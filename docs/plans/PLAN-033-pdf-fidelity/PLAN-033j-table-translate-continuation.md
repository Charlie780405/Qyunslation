# PLAN-033j：表格翻译、矢量重排和续页

> 状态：**已完成**（033n / WT-033n 已关）
> 父计划：[PLAN-033](./PLAN-033-pdf-fidelity.md)
> 验收门：`bash scripts/verify-plan-033j.sh`
> 前置：033i

## 目标

按稳定块 ID 批量翻译表格可译文字；重排保持矢量网格、可搜索文本、字重和角色字号。装不下时按行续页。漏单元格、漏脚注、截断、溢出是硬失败。

## 实现边界

改：

- 表格执行器：按 `block_id` 批量翻译，严格校验 LLM 回包完整性
- 占位符保护：数字、单位、缩写、引用、DOI、URL
- 矢量重排：保留网格线与可搜索文字；表头/分组行粗体继承
- 单语：可增加续页，重复表题+表头，标记“表 X（续）”
- 双语：每个译文续页配对重复原表页，左侧渲染哈希与原稿一致

不改：图片 fitter（033k）、参考文献策略（033h）、整表栅格化（禁止）。

## 失败策略

| 情况 | 动作 |
| --- | --- |
| LLM 漏块 / 块 ID 对不上 | 硬失败 |
| 脚注未入队或未译 | 硬失败 |
| 译文截断或越出单元格 | 硬失败 |
| 双语续页左侧与原稿不一致 | 硬失败 |
