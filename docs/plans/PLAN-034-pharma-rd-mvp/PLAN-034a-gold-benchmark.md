## 目标

建立三类金标场景的样本目录、Pharma-MQM 错误分类、基线评测脚本与发布阈值；样本只记录目录、标签与哈希，**不提交真实资料**。

## 交付

1. `docs/gold/`（或约定路径）下的 **清单文件**（路径、标签、SHA-256、语言向、格式）；真实 PDF/DOCX 仅本机或私有对象存储。
2. **Pharma-MQM** 错误分类表：Critical / Major / Minor；医药专属维度（术语、剂量、否定、引用、表格关系、参考文献保护等）。
3. 基线评测：对当前 `qwen3.6:35b-a3b` 跑三类子集，记录结构性 QC + MQM 抽样。
4. **发布阈值**（与纲领验收对齐）：Critical = 0；硬性术语 ≥98%；禁用译法 = 0；数字/单位/DOI/参考文献保护 = 100%。
5. `verify`：必需样本缺失时 **非零退出 + BLOCKED**（禁止 skip 冒充通过）。扩展 033 的 `QYUNSLATION_PLAN033_SAMPLE` 为多类环境变量或清单驱动。
