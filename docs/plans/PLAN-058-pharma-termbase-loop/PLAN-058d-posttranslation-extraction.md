# PLAN-058d：译后候选提取、对齐与出现位置

> 父计划：[PLAN-058](./README.md)

## 交付

- `/jobs/{job_id}/terms/extract` 幂等接收源词、实际译法、推荐译法、风险、上下文和位置。
- 候选按 `job + source_norm + observed_target` 聚合，重复抽取只补充上下文和出现位置。
- 位置可记录页码、区块、对象、字符范围和 bbox，支持表格/图片/脚注定位。
- 候选保留匹配类型和 termbase 版本，便于解释“为何进入人工队列”。

## 完成定义

- 未确认候选不能自动进入 curated Concept。
- 同一候选重复提交不会创建重复主记录。
- 跨租户 job 不可提取或读取候选。
