# PLAN-059b：Banner 布局与上传后主操作收口

> 父计划：[PLAN-059](./README.md)  
> 状态：待批准  
> 依赖：059a；上一修复：`3cce0ac`

## 交付

- 将应用栏收敛为一个明确的桌面单行布局：状态、方向、模式、帮助、检查器各占固定逻辑槽位，不允许 Gradio `.wrap/.contain` 继承 `100%` 高度。
- 优先采用紧凑 Select/Segmented 控件或显式 CSS grid，消除 Radio 默认卡片横向裁切；移动端另设可换行断点。
- “就绪”使用白色文字及可验证对比度；状态失败/警告仍保留语义颜色和可读背景。
- 上传、删除、预扫描完成和文件切换后，翻译按钮保持显示、可聚焦、可点击，并覆盖无文件/多文件状态。

## 验收标准

- [ ] 1440、1024、768、390 CSS/浏览器断言无重叠、无横向裁切；桌面 Banner 高度不超过设计值。
- [ ] `就绪` 前景色为白色，状态 chip 与深色底对比度达到 WCAG AA。
- [ ] 上传文件后主操作仍在左栏首屏/可视操作路径，事件未重复注册、未白屏。

## 验证、依赖与范围

- 验证：UI 静态门禁、真实浏览器 DOM/截图 smoke、强制刷新和重新登录。
- 依赖：059a。文件：`scripts/apply-pdf2zh-050-workbench.py`、`tests/ui/`、`docs/contracts/ui-runtime-050.md`。
- 规模：Medium。不得把本子计划扩展为重新设计翻译工作台。
