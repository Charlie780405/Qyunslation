# PLAN-059f：表格识别、完整翻译、脚注与样式保真

> 父计划：[PLAN-059](./README.md)  
> 状态：待批准  
> 依赖：059c/059d

## 交付

- 文字层表格走结构网格；扫描/图片表格走表格 OCR；不因无 `Table N` 题注而漏识别，也不把普通 Figure 误报为表格。
- 以 cell/row/column/merged-cell 为单位翻译；表头、正文、表注和脚注全覆盖；缺失 cell、漏译或不完整响应硬失败。
- 统一表格角色字号和行高；继承源粗体、斜体、对齐、边框和合并关系；数字、单位、统计符号和缩写遵守保护策略。

## 验收标准

- [ ] 期刊表格 1–3 和监管表单无题注表格均被识别、翻译并回写；脚注不漏译。
- [ ] 无表格 CJK 残留/空译文/跨格溢出；同角色字号差异不超过 0.75pt，粗体表头保留。
- [ ] 表格缺失、OCR 失败、低置信或无法安全适配时正式稿阻断且保留审阅证据。

## 验证、依赖与范围

- 验证：`table_structure`、`table_translate`、`table_writeback`、监管和文献真实样本门禁；表格 bbox/字号/粗体抽取。
- 依赖：059c、059d、PLAN-041/048/049。文件：`qyunslation/structure/table_*.py`、`pdf_table_translate.py`、相关测试。
- 规模：Large，按扫描/执行/QA 三个提交落地。
