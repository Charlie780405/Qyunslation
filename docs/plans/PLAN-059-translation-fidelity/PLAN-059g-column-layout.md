# PLAN-059g：单栏/双栏/多栏原位排版与段落几何

> 父计划：[PLAN-059](./README.md)
> 状态：实施中（真实多栏行数/行距/段距 QA 待补）
> 依赖：059c/059d/059e/059f

## 交付

- 依据源页面/栏位 bbox 和阅读顺序组装译文；单栏、双栏、多栏及跨栏对象不能跑栏、串栏或覆盖邻栏。
- 固定目标行宽优先，通过自然换行、段落行距、段前/段后距和受控字号适配保持原段落节奏；不以极小字体换取“塞回去”。
- 记录源/译行数、行宽、段距、垂直漂移和溢出；为不可避免的中英文行数差设定角色化容差。

## 验收标准

- [ ] 多栏阅读顺序逐段正确，正文不进入参考文献或相邻栏；跨栏 Figure/Table 位置正确。
- [ ] 同页同角色译文段落的固定行宽、行距、段距保持稳定；垂直漂移和行数差在金标容差内。
- [ ] 任一栏溢出、段落重叠、文字丢失、字号跌破下限都阻断正式稿。

## 验证、依赖与范围

- 验证：单/双/多栏 PDF、DOCX、poster 和 PPTX 视觉回归；文本抽取、bbox、行数和页面 QA。
- 依赖：059c–059f。文件：`structure/layout.py`、`role_fitter.py`、各 PDF/Office exporter、布局测试。
- 规模：Large。
