# PLAN-059d：参考文献保留、标题粗体与缩写脚注策略

> 父计划：[PLAN-059](./README.md)  
> 状态：待批准  
> 依赖：059c

## 交付

- 从参考文献章节标题开始识别 section 范围，整个区域原样保留：章节标题、条目作者、文章标题、期刊、年份、DOI、链接和脚注均不送翻译模型。
- 标题/小标题和表格粗体以源 run/span/IL style 为准；译文继承 bold、italic、颜色和角色层级。
- 建立缩写策略：批准不译的缩写保留原文，但其脚注、全称和解释正常翻译；数字、剂量、注册号和 DOI 按不可变规则处理。

## 验收标准

- [ ] 参考文献区译前请求中不存在文本片段；译后抽取文本与原文 reference section 逐字一致。
- [ ] 加粗标题、表头、分组行和粗体单元格在译文中的粗体比例/角色一致。
- [ ] 缩写本体不误改，脚注和释义无漏译；违规产生可定位 QA 错误。

## 验证、依赖与范围

- 验证：引用区 preserve golden、style parity、缩写/脚注单元测试和译前请求审计。
- 依赖：059c、PLAN-058。文件：`qyunslation/structure/references.py`、`font_style.py`、各译文组装器、`tests/structure/`。
- 规模：Medium。
