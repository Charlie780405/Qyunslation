## 一、目标

建立一条可验证的医药资料翻译链：

`输入识别 → 语义结构真值 → 对象级翻译 → 原位回写 → 版式/术语 QA → 可审计交付`

本计划处理前序记录归并出的 **12 项翻译与排版错误**，并将本次截图暴露的两个 P0 工作台问题一并收口：

1. Banner 内方向、模式、状态和操作控件相互挤压；“就绪”文字与深色底对比不足，必须清晰使用白色文字。
2. Figure/Table 计数与文档实际语义不一致；对期刊金标明确验证 `Figure 1–5 / Table 1–3`，但生产实现不得把这组数字写死。
3. 单栏、双栏、多栏资料未始终按原栏位和阅读顺序原位翻译。
4. 参考文献区仍有部分翻译；参考文献标题、条目标题和章节标题必须整体原样保留。
5. 原文加粗标题在译文中未保持加粗，表格中的粗体同样丢失。
6. 图片翻译存在修改原图、输出污染原文或源/译资源混用的风险。
7. 原文预览缩略图不清晰；图片 OCR/主渲染基准未统一到 300 DPI。
8. 图片译文文字大小不一致，出现溢出、遮挡或小到不可读。
9. 表格未识别、未翻译或只翻译了部分单元格；表格脚注漏译。
10. 表格译文的字体大小在单元格、行和列之间不一致。
11. 缩写保留策略不明确：缩写可按策略不翻译，但其脚注、释义和说明必须翻译。
12. 固定行宽下段落行数、行距和段间距漂移，导致同页/同栏排版与原文差异过大。

## 二、现状判断

- 当前 UI 仍受 Gradio 历史 `.wrap/.contain` 高度和 Radio 默认布局影响；上一提交用 CSS 抢救了可见性，但没有消除控件本身的布局竞争，截图仍显示方向/模式控件横向裁切、互相覆盖。
- 结构层已有 Manifest、Figure/Table 对象和多栏测试，但“物理图片数量、语义 Figure 数量、Table 数量、重复出现次数”尚未在 UI 和交付门禁中统一呈现。
- 现有 PDF、DOCX、PPTX、图片和监管表单路径由不同回写器负责，图片 overlay、表格网格和段落排版的字体/QA 规则没有完全共享。
- PLAN-058 已提供术语解析基础；本计划复用其术语策略包，不训练新模型。模型是否为泰州 `qwen3.6:35b-a3b`、embedding 是否为泰州 `bge-m3`，必须以运行时探针和任务 Manifest 证据确认，不能凭配置文件名称推断。

## 三、验收口径中的“真实数量”

Manifest 必须同时输出以下字段，避免把不同概念混为一个数字：

| 字段 | 含义 |
| --- | --- |
| `physical_image_count` | 页面中实际提取的位图/矢量图片资源数 |
| `semantic_figure_count` | 按题注、编号和跨页归并后的 Figure 数 |
| `table_count` | 独立表格语义对象数，续表按规则归并 |
| `occurrence_count` | Figure/Table 在页面中的出现次数 |
| `unresolved_count` | 无法归属或冲突的对象数，必须显式告警/阻断 |

期刊金标的硬断言为 `semantic_figure_count=5`、`table_count=3`，最大 Figure 编号为 5；其余文件按自身结构真值验收。

## 四、架构决策

1. **结构真值优先。** 先生成可审计 Manifest，再执行翻译；物理资源、语义对象和出现位置分层保存。
2. **源文件不可变。** 原文预览、原始图片和原始表格只读；所有擦除、嵌字、替换和导出写入派生工作副本。
3. **按对象路由。** 正文段落、参考文献、图片、文字层表格、扫描表格、脚注和 PPT 元素分别处理，不用单一 OCR 或单一 BabelDOC 路径兜底所有对象。
4. **参考文献硬保留。** 识别参考文献章节的标题、条目和条目标题后，整体设置 `PRESERVE`；引用编号、DOI、期刊元数据和链接不进入翻译模型。
5. **样式继承而非重新猜测。** 标题/表头/正文/脚注/图片面板建立角色级样式；粗体、字号、颜色和段落间距从源对象继承，再在安全范围内适配目标语言。
6. **300 DPI 主基准、响应式缩略图。** OCR 和图片译后合成使用 300 DPI 主图；浏览器缩略图可以按视口缩放，但不能以低分辨率资源替代主图。
7. **确定性约束优先。** 复用 PLAN-058 的正式术语、数字和不可变字段；只将未知、多义或变体送入模型/向量建议。模型路由必须写入 trace。
8. **失败可见且不可交付。** 漏表、漏脚注、引用误译、原文污染、溢出、过小字体、粗体丢失和数量冲突均产生定位错误；硬错误阻断正式稿。

## 七、总验收门禁

### 结构与完整性

- 期刊金标：语义 Figure `5`、Table `3`，最大 Figure 编号 `5`，无 unresolved 对象。
- 真实文档不得以固定的 `5/3` 代替识别；Manifest 的物理资源、语义对象和 occurrence 数量一致可解释。
- 单栏、双栏、多栏、图表混排、续表、无题注图片、纯图片页均有定位结果。
- 参考文献章节（含章节标题、条目、文章标题、DOI、期刊信息）与原文逐字保留，不进入翻译请求。

### 图片与表格质量

- OCR/合成主图 DPI 为 `300`；原文图片 hash 在翻译前后不变，译文只写派生文件。
- 图片和表格文字无框外溢出、遮挡或不可读小字；同一角色字号差不超过 `0.75pt`，且不得低于角色下限。
- 表格完整识别并覆盖表头、正文、合并单元格、脚注；脚注必翻译，获批缩写仅本体可保留。
- 源粗体标题、图片面板字母/标题和表格粗体单元格在译文中保持粗体。

### UI 与模型

- 桌面 Banner 一行无重叠、无横向裁切；状态“就绪”使用白色且对比度达到 WCAG AA；移动端可响应式换行。
- 上传文件后翻译按钮仍显示、可聚焦、可点击；预扫描摘要不得把主操作永久推离可视路径。
- Manifest/trace 明确记录翻译模型、endpoint、embedding 模型、语言方向、术语库版本和降级状态；LIVE 环境确认 Qwen 与 bge-m3 均为泰州服务时才标记通过。

### 回归与性能

- 聚焦测试、结构全量、PLAN-028/029/030e、034、041、045、050、058 门禁均 PASS；任何 FAIL/BLOCKED 不得报告完成。
- 300 DPI 和多栏回写不改变既有性能硬门；大图/大表使用可观测超时与可恢复失败，不静默降级为漏译。

## 八、范围边界与风险

- 本计划不下载或分发版权样本；金标从知识库或用户指定路径提供，仅用于本地/授权环境验收。
- 本计划不训练翻译模型；优先使用术语库、结构化提示、硬约束、样式继承和 QA。微调另立计划。
- 不直接修改 `site-packages` 作为长期方案；生产行为必须由仓库补丁脚本和部署流程重现。

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| Gradio 旧 CSS 与新布局竞争 | Banner 再次挤压 | 单一 appbar DOM、明确 grid/flex 契约、桌面/移动双断点测试 |
| PDF 表格既有文字层与扫描表格混杂 | 漏表或重复表 | Manifest 对象归属、文字层优先、OCR 仅对无文本证据区域启用 |
| 目标语言文字膨胀 | 图片/表格溢出或微字 | 角色级 fitter、换行/缩放上限、无法安全适配则阻断 |
| 参考文献误进入模型 | 版权信息/标题被改写 | section 级 PRESERVE、请求前断言、译后逐字 hash/文本比对 |
| 运行时模型地址漂移 | 无法复现质量 | health/trace 记录，allowlist 校验，失败明确 BLOCKED |
