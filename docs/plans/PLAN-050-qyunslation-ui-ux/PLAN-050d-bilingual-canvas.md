# PLAN-050d：原文/译文双画布与对象锚点

> 状态：**完成**
> 父计划：[PLAN-050](./PLAN-050-qyunslation-ui-ux.md)
> 依赖：[050b](./PLAN-050b-workbench-shell.md)、[050c](./PLAN-050c-upload-preflight-task.md)

## 目标

把原文和译文预览提升为主工作区，提供 300 DPI 或等效高清渲染、页/对象锚点同步、缩放、旋转、全屏和单/双/多栏可读布局。

## 任务

### Task 1：页面渲染与工具栏

- 原文/译文画布共享页导航，但各自保留缩放、旋转和加载状态。
- 先显示稳定尺寸的低清占位，再按需替换高清资源，避免布局跳动。
- 工具栏按钮有文字名称、快捷键和可见焦点，不遮挡正文。

**验收：** 目标样本页面清晰可读，原文不被任何译文操作修改。

### Task 2：页/对象锚点同步

- 用 `page_id/object_id/occurrence` 关联原译文，不以百分比滚动作为唯一依据。
- 支持旋转页、不同页高、跨页表、单栏/双栏/多栏和对象缺失降级。
- 选中题注、表格、图片文字或正文时，两侧高亮同一语义对象。

**验收：** 金样对象可从摘要、QA、原文或译文任一入口准确定位。

### Task 3：响应式画布

- `>=1440px` 可调双画布；`1024–1439px` 检查器抽屉；`<1024px` 原/译文切换。
- 页面缩小时不使用微字体强行保留双栏；窄屏主操作固定且不遮挡安全区。

**验收：** 320/768/1024/1440px 无横向溢出、译文栏裁切或滚动失联。

## 文件范围

- 画布/预览、页导航、缩放旋转、Manifest 锚点适配、响应式布局、测试和 WT-050d。
