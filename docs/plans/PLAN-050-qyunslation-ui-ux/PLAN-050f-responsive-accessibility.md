# PLAN-050f：响应式、无障碍与性能收口

> 状态：**完成**
> 父计划：[PLAN-050](./PLAN-050-qyunslation-ui-ux.md)
> 依赖：050b–050e

## 目标

让快速翻译和专业审校在窄屏、键盘、读屏、慢网络和长任务下仍然可用，并消除画布、检查器和任务轮询造成的布局跳动与重复计算。

## 任务

### Task 1：断点与输入方式

- 验证 320、768、1024、1440px；建立单画布/双画布/抽屉布局矩阵。
- 触控目标至少 44px；固定底部主操作避开安全区和键盘。
- 大字号和 200% 缩放下核心路径仍可完成。

### Task 2：键盘与读屏

- 上传、开始、取消、原译文切换、页导航、问题跳转、保存和下载均可键盘完成。
- 抽屉/对话框管理焦点，`Esc` 关闭后焦点返回触发器。
- live region 只播报阶段和关键状态，不逐百分比刷屏。

### Task 3：性能和恢复

- 画布、缩略图和检查器按需加载；只渲染可视页；任务只保留单一轮询源。
- 使用 skeleton/稳定尺寸资源，页面隐藏时退避轮询，完成后停止轮询。
- 切换文件、刷新、断线和旧回调不破坏当前任务。

**验收：** Lighthouse/浏览器人工检查、键盘路径、读屏名称、慢网和长文档基线均有记录。

## 文件范围

- 响应式样式、焦点管理、ARIA、渲染调度、任务缓存/轮询和 WT-050f。
