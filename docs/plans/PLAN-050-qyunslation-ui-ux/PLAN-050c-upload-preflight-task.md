# PLAN-050c：上传、预扫描摘要与任务状态

> 状态：**完成**
> 父计划：[PLAN-050](./PLAN-050-qyunslation-ui-ux.md)
> 依赖：[050a](./PLAN-050a-runtime-baseline.md)、[050b](./PLAN-050b-workbench-shell.md)

## 目标

让用户在不阅读技术日志的情况下完成上传、方向确认、预扫描确认、翻译启动、取消、重试和下载等待；所有摘要来自 Manifest。

## 任务

### Task 1：上传与方向

- 支持 PDF、DOCX、常见图片和 PPT/PPTX 的统一上传状态。
- 显示文件名、大小、真实格式、能力结果和方向；自动检测只作建议。
- 伪后缀、损坏、加密、缺依赖和超限错误贴近文件项展示。

**验收：** 每种必需格式均有明确接受、转换、降级或拒绝文案。

### Task 2：Manifest 预扫描卡

- 展示页数、单/双/多栏、Figure、Table、可译图片、表格脚注和参考文献保护。
- 语义对象计数可点击跳转；物理资源数只进入诊断明细。
- `unknown/truncated/blocked/degraded` 显示状态和行动建议，不显示为 0 或成功。

**验收：** `ljae439` 显示 Figure 1–5、Table 1–3；与 Manifest 完全一致。

### Task 3：任务状态机

- 阶段统一为校验、预扫描、文本翻译、表图翻译、版式生成、QA。
- 显式处理排队、执行、取消、超时、失败、重试、恢复和旧代际回调。
- 原始日志移入技术详情，保留可复制错误 ID 和页/对象定位。

**验收：** 刷新、断线、重复点击和取消不会生成重复任务或覆盖新任务。

## 文件范围

- Manifest/任务状态适配器、上传组件、预扫描摘要、进度状态、错误文案和测试/WT-050c。
