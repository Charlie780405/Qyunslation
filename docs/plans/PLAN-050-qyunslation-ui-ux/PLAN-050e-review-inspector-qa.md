# PLAN-050e：对象检查器、术语与 QA 审校

> 状态：**完成**
> 父计划：[PLAN-050](./PLAN-050-qyunslation-ui-ux.md)
> 依赖：[050d](./PLAN-050d-bilingual-canvas.md)

## 目标

建立以页面对象为中心的专业审校能力，优先解决当前最影响医药资料交付的问题：表格未识别/未翻译、脚注漏译、图片文字字号异常、参考文献误译和数字/剂量变化。

## 任务

### Task 1：通用对象检查器

- 展示对象类型、页码、语义 ID、原文、译文、版式状态和历史。
- 正文/标题、表格单元格、图片 OCR、题注、脚注使用适配编辑器。
- 原文只读；译文编辑可保存、撤销、冲突提示和代际追踪。

**验收：** 从画布或问题列表打开对象后，页面定位、检查器和保存状态一致。

### Task 2：表格与图片审校

- 表格支持单元格、合并单元格、粗体、对齐、字号层级和脚注状态。
- 图片支持原图、OCR 框、译文框、置信度、粗体/字号/对齐和溢出状态。
- 缩写可保护，但脚注和解释文本不能因此跳过；所有未译对象都进入 QA。

**验收：** 旋转大表、表格脚注、流程图、纯图片页和图表混排均可定位/编辑/恢复。

### Task 3：术语、TM 与 QA

- 展示首选译法、保护/不译、禁用译法、变体、词库版本和来源。
- QA 分阻断/警告/信息，覆盖术语、数字/剂量、漏译、格式、表图、脚注、参考文献和溢出。
- 每条问题可跳转、解决、忽略并记录理由；导出前重新执行文档级 QA。

**验收：** 参考文献整区原样保留；阻断问题会阻止正式导出但允许审阅稿下载。

## 文件范围

- 对象检查器、表格/图片审校、术语/TM/QA 适配器、历史状态、测试和 WT-050e。
