# PLAN-050g：真实运行时验收与交付

> 状态：**完成**
> 父计划：[PLAN-050](./PLAN-050-qyunslation-ui-ux.md)
> 依赖：050a–050f

## 目标

在真实提供服务的界面上完成 UI/UX、结构 Manifest、浏览器行为和生产补丁的联合验收，形成可回滚交付证据。

## 任务

### Task 1：样本矩阵

- PDF：单栏、双栏、多栏、旋转表、图表混排、参考文献、扫描页。
- DOCX：节/栏、原生表格、文本框、图片 occurrence、页眉页脚。
- 图片/PPT/PPTX：纯图片、Poster、图片文字、原生/图片化幻灯片。
- 失败：伪后缀、损坏、加密、缺能力、超时、截断和低置信度。

**验收：** 每个样本有输入 hash、Manifest 摘要、结果截图、问题数和输出可编辑性记录。

### Task 2：自动与浏览器门禁

- 运行 Skill 校验、结构/Manifest 测试、前端构建、UI 单测和端到端任务流。
- 使用真实服务进行上传、预扫描、翻译、QA、下载和刷新恢复。
- 检查 console、网络 404、重复请求、资源加载、键盘和窄屏。

**验收：** 任一必需项 FAIL/BLOCKED 都不能报告通过；缺样本必须诚实标 BLOCKED。

### Task 3：部署、补丁签名与回滚

- 验证补丁顺序、幂等、最终服务页面和旧版本回滚。
- 记录部署前后提交、运行时版本、Manifest schema、字体/DPI、模型网关和词库版本。
- 形成 [WT-050g](../../walkthroughs/WT-050g-ui-ux-delivery.md)。

**验收：** 可从证据复现当前 UI；回滚后旧任务和下载能力不受破坏。
