# PLAN-050b：工作台壳层与统一设计系统

> 状态：**完成**
> 父计划：[PLAN-050](./PLAN-050-qyunslation-ui-ux.md)
> 依赖：[050a](./PLAN-050a-runtime-baseline.md)

## 目标

建立文档画布优先的工作台骨架：应用栏、左侧工作坞、中央画布占位、右侧检查器占位、快速/专业模式和统一视觉令牌。

## 任务

### Task 1：令牌与基础控件

- 固化颜色、间距、字体、边界、状态、焦点和动效令牌。
- 替换新增代码中的硬编码色值、Bootstrap/Tailwind 混用和无标签图标。
- 恢复 `focus-visible`，统一按钮、输入、标签、抽屉、通知和状态徽标。

**验收：** 令牌可集中修改；键盘焦点可见；状态不只依赖颜色。

### Task 2：三栏工作台骨架

- 应用栏显示文档名、方向、任务状态和帮助。
- 左侧工作坞容纳上传、队列、基本选项和主操作。
- 中央区域预留原译文画布；右侧检查器默认收起或显示文档摘要。
- 不让原始日志、内部 task ID 或高级工程参数成为主视觉。

**验收：** 长文件名、空状态和错误状态不裁切；中央区域在桌面端保持主导。

### Task 3：模式和布局状态

- 快速模式只显示完成任务所需选项；专业模式按需打开审校面板。
- 模式切换不创建新任务、不丢失当前页/对象/编辑内容。
- 各栏可收起；最小宽度和窄屏降级由布局状态统一控制。

**验收：** 同一任务在两种模式之间切换可恢复；无重复轮询或重复任务。

## 文件范围

- 以 050a 识别出的实际运行时文件为准；不预先假设 Vue 或 Gradio。
- 预期涉及：设计令牌、布局组件、基础控件、UI 样式测试和 WT-050b。

## 完成定义

- [x] 桌面三栏骨架可进入、可收起、无横向溢出。
- [x] 快速/专业模式只改变信息密度，不分裂任务模型。
- [x] 基础控件具备语义标签、键盘焦点和错误状态。
