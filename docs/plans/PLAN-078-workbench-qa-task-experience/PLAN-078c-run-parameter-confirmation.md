# PLAN-078c：每次翻译前参数确认（P1）

> 状态：未实施 · 依赖：078a（与 078b 并行）· 工作量：5–7 人日 · 对应问题：P1–P9、Q4（预检 TTL 部分）

## 目标

新建、复制配置、重新翻译和生成修订版之前，都要在确认抽屉里看到并可以修改最终配置。确认内容、请求体、服务端解析、执行器命令和冻结快照五者一致。临时调整不会污染默认值。改了关键参数就不会再拿到旧任务。

## 任务

### c1 配置校验接口（dry-run）

- **内容**：新增 `POST /translation-runs:validate`，入参与创建接口相同。返回：服务端解析后的完整配置（语言、文档类型、领域、资料等级、翻译模型、术语模型、外发范围、执行器能力、QA 策略）；校验结果，按 error/warning 区分（语言相同、模型不可用、领域不支持、等级与外发冲突、泰州术语服务当前不可达（D1，只作 warning，不阻止提交）、预检已过期或已被使用）。返回的配置中包含实际采用的术语模型档案（如 `term-internal-qwen`）及其外发范围；`config_digest`（规范化后取 SHA-256）。复用 `validate_selection`、`_validate_domain_profile`、`build_run_model_snapshot`，不另写一套逻辑。
- **文件**：`v1.py`（可拆出 `api/runs_config.py`）
- **工作量**：1.5 人日

### c2 确认抽屉

- **内容**：新组件 `RunConfirmDrawer.vue`，按主计划 §4.4 线框实现。每个字段标注来源（默认/上次/本次修改/冻结快照）并高亮与默认值的差异；模型被自动替换时显式提示（P8）；保存方式默认“仅本次生效”。“确认并开始”在校验结果为最新且没有 error 时才可用，禁用原因直接显示在按钮旁。原参数侧栏改为抽屉内容的唯一来源，不再保留第二套表单。
- **验收**：A8 的界面部分；键盘可以完整操作；关闭后焦点回到触发按钮。
- **工作量**：1.5–2 人日

### c3 偏好解耦（部分完成：服务端白名单已修，见总纲 §12）

- **内容**：删除 `watch(workbenchState, scheduleWorkbenchPreferenceSave)`（`WorkbenchPage.vue:530`），只在选择“保存为默认”时 PUT；保存失败要提示，不再静默。服务端白名单加入 `modelProfileId` 和 AD 文档类型，并做校验（`v1.py:76-78`、`:437`）（P2/P3）。
- **工作量**：0.5 人日

### c4 幂等与配置摘要（部分完成：服务端 `config_digest` 与 409 已落地，见总纲 §12）

- **内容**：前端每次打开确认抽屉生成一个 UUID 作为 `Idempotency-Key`，请求附带 `config_digest`。服务端用同一 key 查到已有任务时比较摘要：一致则返回原任务；不一致返回 409 `IDEMPOTENCY_CONFIG_MISMATCH`，取代现在只比较 `domain_profile` 的逻辑（`v1.py:2014-2028`）。服务端重新计算摘要，与请求不一致（参数在确认后被改过）时返回 409 `CONFIG_STALE`，并要求重新确认。
- **验收**：连点只创建一个任务；改模型或资料等级后提交会创建新任务，或给出明确冲突提示，不会返回旧任务（P4）。
- **工作量**：1 人日

### c5 预检与源文件生命周期

- **内容**：
  - 被任何未清除任务引用的预检源文件不受 24 小时 TTL 约束（`v1.py:86`），TTL 只回收未使用的预检；
  - `GET /preflights` 返回 `used_by_run_id`，恢复时不再提示“可直接开始”（P7）；
  - 修改语言方向或领域时，由 validate 判断是否需要重新预检（AD 领域证据依赖源文本）；
  - “同一源文件换配置”不再要求重新上传：服务端复制预检记录和源文件，新建一条预检（拷贝成本可接受，删除语义简单），之后用这条新预检创建新任务（P6）。
  - `DELETE /preflights/{id}` 在仍有引用时返回 409（T4 的一部分）。
- **验收**：48 小时前完成的 QA 阻断任务仍可生成修订版；同一文件可以用两套配置各跑一次，互不影响。
- **工作量**：1 人日

### c6 输出选项真实化（PDF 已接入 `--no-dual`，其余格式已禁用该选项，见总纲 §12）

- **内容**：核对当前安装的 `pdf2zh_next` 是否支持单/双语输出参数，以及 Office 路径能否只出单语（H10）。支持的话，把 `bilingual` 接入 `build_pdf2zh_command`（`runner.py:215-267`）和 Office 适配器；不支持的话，从抽屉中移除该选项，改为说明“系统同时生成译文与对照稿”。
- **验收**：快照、执行器命令和产物三者一致。契约测试：对每个字段断言 UI → 请求 → 快照 → `build_pdf2zh_command` 参数。
- **工作量**：0.5–1 人日

### c7（可选，后续增强）页码范围与 OCR

执行器已经支持 `pages`、`ocr_workaround`、`scan_strategy`（`runner.py:250-266`）。开放前需要确认 QA 在只译部分页时的口径（页数比较、漏译判断），否则会制造新的误报，所以本期不做。

## 重新翻译与续跑

- 重新翻译和修订版：抽屉预填旧版冻结快照，高亮改动，提交后生成新版本（078b b6）。
- 断点续跑：抽屉只读展示冻结快照，按钮写“按原配置续跑”；如需修改，入口改为“生成修订版”。
